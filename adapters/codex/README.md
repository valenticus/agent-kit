# Codex adapter

Codex discovers repository instructions from `AGENTS.md` and project skills from `.agents/skills/<name>/SKILL.md`. The installer copies approved core and vendored optional selections there; referenced optional modules use their separately approved source. A fresh install creates `AGENTS.md` from `templates/project-rules/AGENTS.md` when none exists; complete its placeholders in that file. An existing `AGENTS.md` is never overwritten by a normal install: merge the template's project-specific structure into it by hand, and receive universal managed policy updates through `install.ps1 -UpdatePolicies`. Never overwrite generated framework blocks or project rules blindly.
