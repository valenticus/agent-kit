# Mobile design

Load the current project's UI and product hooks. Design from a narrow viewport and the actual usage context.

- Keep the goal and essential context early in the scan path; make frequent actions reachable without duplication.
- Use navigation for stable peer destinations, sheets for focused reversible context, and full screens for deep work.
- Avoid nested scrolling and hidden content beneath keyboards or sticky controls.
- Make labels, values, validation, consequences, touch targets, and destructive actions unambiguous.
- Specify relevant loading, empty, error, disabled, success, slow-network, and offline states.
- Check safe areas, text expansion, orientation, reduced motion, keyboard and screen-reader access, contrast, and recovery paths.

Review task cost and hierarchy before visual polish.
