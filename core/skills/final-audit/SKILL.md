# Final audit

Establish comparison base, intended scope, changed files, known user changes, and applicable project hooks. Review correctness, access boundaries, migrations/data compatibility, user flows and states, tests, operations, and delivery risk as relevant.

Run focused and repository-wide checks only when safe and useful. Report findings first by severity with precise locations and impact, then checks, gaps, assumptions, residual risk, and a release recommendation. Do not silently implement unrelated fixes.
